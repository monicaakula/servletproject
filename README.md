\# Java Servlet Project



A simple Java Servlet web application developed using \*\*Java\*\* and \*\*Apache Tomcat\*\*.



\## Technologies Used



\* Java

\* Java Servlet

\* Apache Tomcat

\* HTML

\* Git \& GitHub



\## Project Structure



```text

servletproject/

├── src/

│   └── MyServlet.java

├── lib/

│   └── servlet-api.jar

├── .vscode/

│   └── settings.json

├── .gitignore

└── README.md

```



\## How to Run



1\. Install Java JDK.

2\. Install Apache Tomcat.

3\. Compile the servlet using the Servlet API.

4\. Deploy the application to the Tomcat `webapps` folder.

5\. Start Tomcat.

6\. Open the application in a browser.



Example:



```text

http://localhost:8080/servletproject/

```



\## Purpose



This project was created to learn and practice Java Servlet programming and web application development using Apache Tomcat.
